# Docfilly ドキュメント

Docfillyは、非エンジニアでも扱えるシンプルな可変ドキュメントフォーマットです。通常のMarkdown／プレーンテキストへ設定項目を加えると、編集フォームとリアルタイムプレビューを生成できます。

Docfilly形式の文書は、ファイルの先頭に`#!docfilly`と書くだけで明示できます。識別子がないファイルは、通常のMarkdown／テキストとしてそのまま表示します。

記述を厳密に検査して処理を止めるのではなく、読み取れる部分を利用して可能な限り文書を表示します。問題がある箇所は、表示を妨げない「注意点」として確認できます。

## まず試す

```sh
pnpm install
pnpm dev
```

開発サーバーのURLをブラウザで開き、`.md`、`.markdown`、または`.txt`ファイルを選択します。サンプル文書はファイルを選択しなくても表示されます。

ライブラリだけを利用する場合は、[はじめに](./02-getting-started.md)を参照してください。
