# Webデモ

## 概要

`apps/web`は、Docfillyライブラリを利用したViteアプリです。ユーザーがローカルファイルを選択するか、画面上部のドロップ領域へドラッグ＆ドロップすると、ブラウザ内で内容を読み取り、フォームとプレビューを表示します。

```sh
pnpm dev
```

## 対応ファイル

- `.md`
- `.markdown`
- `.txt`

拡張子が`.md`または`.markdown`の場合はMarkdown、それ以外の許可されたファイルはプレーンテキストとして扱います。

## ファイル読み込みの流れ

1. `<input type="file">`からユーザーがファイルを選択するか、画面上部の領域へファイルをドラッグ＆ドロップします。
2. File APIの`file.text()`でソース文字列を取得します。
3. ファイル名から`"md"`または`"text"`を判定します。
4. `createDocfilly`で新しい表示インスタンスを作ります。先頭が`#!docfilly`なら設定フォームを生成し、識別子がなければ通常文書として表示します。
5. 以前のインスタンスへ`destroy()`を呼び出します。
6. 新しい`element`をビューアーへ配置します。

```ts
const source = await file.text();
const sourceType = file.name.endsWith(".md") ? "md" : "text";
const view = createDocfilly(source, sourceType);
viewer.replaceChildren(view.element);
```

実際の実装では`.markdown`もMarkdownとして判定し、読み飛ばした設定や自動補正があれば、画面のステータス領域へ注意点を表示します。

ドラッグ中はドロップ領域の枠と背景が変わり、ドロップできる場所を示します。ファイルは1つずつ読み込みます。複数ファイルまたは対応外の拡張子をドロップした場合は、現在の文書を維持してステータス領域へ案内を表示します。

## プライバシー

選択されたファイルはブラウザのFile APIで読み込まれます。現在のデモにはアップロード処理や外部API通信はなく、ファイル内容はサーバーへ送信されません。

## 初期サンプル

ファイルを選択する前でも機能を確認できるよう、アプリ内にサンプルMarkdownを持っています。サンプルには次の3種類が含まれます。

- テキスト入力
- ドロップダウン
- チェックボックス

## 注意点の表示

次のような記述があっても、ライブラリは文書全体の表示を止めません。

- `#!docfilly`があるのに`---`区切り行が存在しない場合は、識別子より後を本文として表示
- 設定行に`=`がない場合は、その行だけを読み飛ばす
- 使用できない設定名は、その設定だけを読み飛ばす
- 設定名が重複した場合は、最初の設定を使用
- 空のドロップダウン選択肢は、空の項目だけを除外

Webデモは生成されたフォームと文書を表示したうえで、ステータス領域に注意点の件数と最初のメッセージを表示します。すべてのメッセージはステータス領域の`title`属性からも確認できます。

識別子がないファイルは問題のない通常文書として扱うため、注意点は表示しません。

ファイル自体を読み込めなかった場合だけは、新しい文書へ切り替えず、もう一度選択するよう案内します。
