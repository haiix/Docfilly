# [[project_name]] 5分チュートリアル

まずは左のフォームで「プロジェクト名」「実行環境」「チームで作業する」を変更してみてください。右側の見出しや手順がその場で変わります。デスクトップでは、本文を下へ読み進めてもフォームがツールバーの下へ追従します。

Docfillyは、通常のMarkdown／テキストに少数の構文を追加し、文書の読み替えを支援するためのドキュメントフォーマットです。

## 基本構造

Docfilly文書は、先頭行に`#!docfilly`を書き、`---`の区切り線より前に**フォーム設定**、後ろに**本文テンプレート**を書きます。

```text
#!docfilly

(フォーム設定)

---

(本文テンプレート)
```

## 1. テキストを差し込む

### 左のフォームで試すこと

「プロジェクト名」や「作成者」を変更すると、下の表示結果にも同じ値が反映されます。

### フォーム設定

```text
project_name | プロジェクト名 = Docfilly
author | 作成者 = 山田太郎
```

左から「変数名 | ラベル = 初期値」です。`| ラベル`は省略でき、その場合は変数名がフォームのラベルになります。本文に変数名を二重角括弧（`\[[変数名]]`）で書くと、入力した値に置き換わります。

### 本文テンプレート

```text
現在のプロジェクト名は **\[[project_name]]** です。
作成者: **\[[author]]**
```

### 表示結果

> 現在のプロジェクト名は **[[project_name]]** です。
>
> 作成者: **[[author]]**

## 2. 選択肢で表示を変える

### 左のフォームで試すこと

「実行環境」で本番環境を選ぶと、下の案内が切り替わります。

### フォーム設定

```text
environment | 実行環境 = [development, *staging, production]
```

角括弧内に選択肢を並べ、`*`を付けた項目を初期選択にします。

### 本文テンプレート

```text
現在の選択: **\[[environment]]**
\[[#if environment = production]]
本番環境です。変更前にレビューとバックアップを確認してください。
\[[#else]]
本番前の環境です。変更内容を確認できます。
\[[#endif]]
```

本文で、`\[[#if 変数名 = 値]]`のように書くと、条件を満たす内容だけを表示できます。`\[[#else]]`でそれ以外の内容へ切り替え、`\[[#endif]]`で終了します。

### 表示結果

> 現在の選択: **[[environment]]**
>
[[#if environment = production]]
> 本番環境です。変更前にレビューとバックアップを確認してください。
[[#else]]
> 本番前の環境です。変更内容を確認できます。
[[#endif]]

## 3. チェックで手順を切り替える

### 左のフォームで試すこと

「チームで作業する」のチェックを切り替えると、作業手順が変わります。

### フォーム設定

```text
team_work | チームで作業する = [x]
```

`[x]`はON、`[ ]`はOFFのチェックボックスを作ります。

### 本文テンプレート

```text
\[[#if team_work]]
### チームで作業する場合

1. 作業ブランチを作成します。
2. 変更後にレビューを依頼します。
\[[#else]]
### 個人で作業する場合

1. 手元で変更内容を確認します。
2. 作業内容を記録します。
\[[#endif]]
```

### 表示結果

[[#if team_work]]
> ### チームで作業する場合
>
> 1. 作業ブランチを作成します。
> 2. 変更後にレビューを依頼します。
[[#else]]
> ### 個人で作業する場合
>
> 1. 手元で変更内容を確認します。
> 2. 作業内容を記録します。
[[#endif]]

## 次は自分の文書で試す

1. ツールバーの「Docfilly形式で保存」で、このソースをダウンロードします。
2. 保存したファイルをテキストエディターで編集します。
3. ツールバーの「ファイルを開く」から、編集したファイルをもう一度開きます。

すべての記法は[詳細なDocfillyフォーマット仕様](https://github.com/haiix/Docfilly/blob/main/documents/03-source-format.md)で確認できます。
